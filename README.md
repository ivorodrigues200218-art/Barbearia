# Barbearia Portfolio

Projeto de portfólio para demonstrar habilidades de desenvolvimento web e controle de versão com Git/GitHub.

## Sobre o Projeto
Site institucional para uma barbearia, que contem página inicial, serviços, galeria e formulário de contato.

## Tecnologias Utilizadas
- HTML5
- CSS3
- JavaScript

## Como rodar o projeto
1. Clonar o repositório.
2. Abrir o arquivo `index.html` no navegador.
